# Printer Online SP

A self-contained Python web app for online print ordering.

## Features

- User login for print customers (`user` / `user123`).
- Admin login for shop operators (`admin` / `admin123`).
- Upload PDF or image files for printing.
- Choose mono/black-and-white or colour printing and copy count.
- Calculate the amount in rupees from admin-controlled per-copy rates.
- Generate a payment QR-style display for the exact amount and configured payment account.
- Simulate payment success/failure:
  - successful payments dispatch the job to the configured/default printer or queue it safely;
  - failed payments are blocked and never printed.
- Admin dashboard for mono/colour pricing, payment account, optional printer command, payment transaction history, and document history.

## Run locally

```bash
python3 app.py
```

Open <http://127.0.0.1:8000>.

The application runs with the Python standard library. Install `requirements.txt` to enable a scannable payment QR generated by the `qrcode` package; without that optional dependency, the app displays a deterministic QR-style fallback. It creates local data in `data/`, including the SQLite database and uploaded documents.

```bash
python3 -m pip install -r requirements.txt
```

## Printer configuration

In the admin dashboard, set **Printer command** when the web app is running on the admin machine connected to the printer. You can use these placeholders:

- `{file}` - uploaded file path
- `{copies}` - selected copy count
- `{type}` - `mono` or `color`

Example:

```bash
lp -n {copies} {file}
```

If no command is configured, the app tries the operating system default `lp`/`lpr` command. If neither exists, paid jobs are marked as queued rather than printed.

## Notes for production

This repository is a runnable prototype. Before using real payments or public traffic, connect it to a verified payment gateway callback/webhook, replace the demo credentials, use HTTPS, and configure a trusted print service account.
